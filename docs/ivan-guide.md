# How to use the admin

Go to the website and add /admin/ to the address. Log in with your email.

On the left you see the sections: Food & Dining, Hangout Spots, Wellness & Fitness, Fun & Family, Deals & events, and Categories & types.

To add a venue, pick a section, click New, fill in the form, and click Publish. Set the Area to Canggu or Uluwatu — that decides which page it shows on. Pick one or more types (Brunch, Bars, Yoga…). For photos, click Choose an image then Upload — no links needed. For Instagram, you can paste the full link or just the username like @cratecafe. WhatsApp links like wa.me/62812… work too, the site adds https:// automatically.

To change a venue, use the search box at the top to find it, make your changes, and Publish.

The "Our Top Pick" badge is a switch on each venue. Use the Filter button and pick "Top picks only" to see which ones have it. Right now 23 hangout venues have it — you can untick the ones you want.

To add a new type (like "Rooftop"), go to Categories & types, open the section, click Add type, name it, and Publish. After about 2 minutes reload the admin page and the new type appears in every venue form.

After you press Publish, the website rebuilds itself. A timer shows at the bottom of the screen. When it reaches zero, open the website and reload the page. If nothing changed yet, give it one more minute.
