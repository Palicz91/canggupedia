# How to use the admin

Go to the website and add /admin/ to the address. Log in with your email.

On the left you see the sections: Food & Dining, Hangout Spots, Wellness & Fitness, Fun & Family, Venue order, Deals & events, and Categories & types.

Save is not the same as online. Save keeps your change. The website doesn't know yet. When you're done for the day, press Put online now in the bar at the bottom of the screen. About 2 minutes later, reload the website. Press it once at the end, not after every change.

To add a venue, pick a section, click New, fill in the form, and click Save. Set the Area to Canggu or Uluwatu, that decides which page it shows on. Pick one or more types (Brunch, Bars, Yoga…). For photos, click Choose an image then Upload. No links needed. For Instagram, paste the full link or just the username like @cratecafe. WhatsApp links like wa.me/62812… work too.

To change a venue, type its name in the search box at the top, click it, make your changes, and Save.

For opening hours, open the place on Google Maps, copy the whole week, and paste it into the Opening hours box. The website splits it into one line per day and puts today's line in bold. If you'd rather write one line like "8AM – 10PM", that still works and shows exactly as you typed it.

To change the order venues appear in, go to Venue order and pick Canggu or Uluwatu. Each section has one list for the whole section, then one list per type under it. Drag the rows to reorder. The list for the whole section is what the All tab shows. If you want a different order on just one tab, use that tab's own list — put Billy Ho at the top of "Food & Dining — Dinner tab only" and he is first on Dinner without moving on All. Leave a type's list empty and that tab follows the whole-section order, which is what all of them do today.

A venue you just added is not in these lists yet, so it sits at the bottom of the website page until you put it in. Scroll to the bottom of the right list, click Add venue, and type its name into the new row.

The "Our Top Pick" badge is a switch on each venue. Use the Filter button and pick Top picks only to see which ones have it. Right now 23 hangout venues have it. Turn off the ones that shouldn't.

To add a new type (like "Rooftop"), go to Categories & types, open the section, click Add type, name it, Save, then Put online now. After about 2 minutes reload the admin page and the new type is in every venue's Type list.

If you delete something, the bar at the bottom won't count it. Press Help, then Put online now.
