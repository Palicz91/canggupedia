How to use this

Save is not the same as online

Save keeps your change. The website doesn't know yet. When you're done for the day, press Put online now in the bar at the bottom. About 2 minutes later, reload the website.

Press it once at the end, not after every change.

Add a venue

Pick a section on the left → New → fill in the form → Save.

Change a venue

Type its name in the search box at the top → click it → change what you want → Save.

Change a photo

Choose an image → Upload → pick a photo from your computer. No links needed.

Uluwatu or Seminyak

Same as Canggu. Set Area to Uluwatu inside the venue. That's all.

Add a type (Brunch, Padel, Rooftop…)

Categories & types → open the section → Add type → Save → Put online now. After 2 minutes, reload this page and the new type is in every venue's Type list.

“Our Top Pick” badge

A switch on each venue. Filter → Top picks only shows which venues have it.

Removed something?

Deleting doesn't show in the bar. to send it to the website.
