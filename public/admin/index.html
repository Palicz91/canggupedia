How to use this

Add a venue

Pick a section on the left (Food, Hangout, Wellness, Fun & Family) → New → fill in the form → Publish.

Change a venue

Type its name in the search box at the top, click it, change what you want → Publish.

Change a photo

Click Choose an image → Upload → pick a photo from your computer. No links needed.

Uluwatu (or Seminyak) venues

Same as Canggu. Just set Area to Uluwatu inside the venue. It shows up on the Uluwatu page automatically.

Add a type (Brunch, Padel, Rooftop…)

Left menu → Categories & types → open the section → Add type → Publish. After 2 minutes, reload this page and you can pick it on any venue.

“Our Top Pick” badge

It’s the switch called Show “Our Top Pick” badge on each venue. Use the Filter button → Top picks only to see which ones have it.

After you press Publish

The website rebuilds itself. It takes about 2 minutes. A timer shows at the bottom of the screen. When it hits zero, reload the website.
